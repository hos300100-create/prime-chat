# PRIME Blue Live Chat

واجهة شات PRIME زرقاء برسائل Kick الحقيقية، مع دعم بادجات MOD وOG وVIP. يوجد وضع شات كام فل سكرين يطابق فكرة المقطع، بالإضافة إلى الشات العمودي القديم.

## طريقة التشغيل

### 1) ارفع الخدمة إلى استضافة عامة

هذه الحزمة تستخدم Webhooks الرسمية من Kick، لذلك لازم يكون عندها رابط HTTPS عام يستقبل أحداث الشات. فك ضغط الملف، ثم ارفع مجلد `prime-kick-chat` إلى مستودع GitHub. في Render أنشئ **New Web Service** واربط المستودع، ثم اختر:

- Runtime: `Node`
- Build command: `npm install`
- Start command: `npm start`

بعد النشر انسخ رابط الخدمة، مثل `https://اسم-الخدمة.onrender.com`.

### 2) أنشئ تطبيق Kick Developer

من لوحة Kick Developer أنشئ تطبيقًا وحدد:

- Redirect URL: `https://اسم-الخدمة.onrender.com/auth/callback`
- Webhook URL: `https://اسم-الخدمة.onrender.com/webhooks/kick`
- فعّل Webhooks، واسمح بالـ scopes: `user:read` و`events:subscribe`

### 3) أضف متغيرات البيئة في الاستضافة

- `PUBLIC_BASE_URL` = رابط الخدمة العام من دون `/` في النهاية
- `KICK_CLIENT_ID` = Client ID للتطبيق
- `KICK_CLIENT_SECRET` = Client Secret للتطبيق

أدخل Client Secret مباشرةً في إعدادات الاستضافة فقط. لا ترسله في المحادثة ولا تضعه في ملفات الموقع.

### 4) اربط حسابك واشترك في الرسائل

بعد إعادة تشغيل الخدمة افتح `https://اسم-الخدمة.onrender.com/auth/kick` وسجّل الدخول بحساب صاحب قناة iPrime0 ووافق على الصلاحيات. بعد الموافقة، الخدمة تنشئ اشتراك `chat.message.sent` وتتحقق من توقيع Webhook القادم من Kick.

### 5) أضف شات كام في OBS

أضف الكاميرا إلى المشهد أولًا، ثم أضف **Browser Source** فوقها وضع الرابط:

`https://اسم-الخدمة.onrender.com/chatcam`

اضبط العرض **1920** والارتفاع **1080**. الخلفية شفافة؛ لذلك ستظهر الكاميرا تحت العنوان والشات العائم على اليمين. يظهر العنوان **JUST CHATTING**، وتُعرض رسائل Kick مباشرة بعد ربط الحساب.

### الشات العمودي القديم

في OBS اختر **Sources → + → Browser**، وضع رابط:

`https://اسم-الخدمة.onrender.com/overlay`

اضبط العرض **294** والارتفاع **733**.

## فحص سريع

- `/health` يعرض حالة الخدمة والربط.
- `/` يعرض صفحة الإعداد.
- `/chatcam` واجهة شات كام شفافة فل سكرين (1920 × 1080).
- `/overlay` واجهة الشات العمودي (294 × 733).
- رسائل الشات لا تظهر إلا بعد إعداد Webhook وربط الحساب.

لا يحتوي المشروع على مفاتيح أو بيانات دخول؛ أنت تدخل أسرار تطبيقك داخل لوحة الاستضافة.
